# Name: ui-design-system
## Descrição: Sistema de Design de Alto Contraste (Estilo Paramount+).

- **Estética:** Minimalista, alto contraste, moderno, Tema Claro (Light Mode).
- **Cores:** 
  - Fundo: Branco (#FFFFFF) / Cinza Extra Leve (#F8F8F8).
  - Texto: Preto (#000000) / Cinza Médio (#666666).
  - Ações: Verde Sucesso (#2ECC71) para Stock/Faturamento; Vermelho (#E74C3C) para Erros/Excluir.
  - PROIBIÇÃO: Não utilizar a cor Azul.
- **Tipografia:** Sans-serif (Inter/Roboto). Títulos em Uppercase com letter-spacing aumentado.
- **Inputs:** OutlineInputBorder, borda 1px cinza, 2px preto no foco. Raio: 4px.
- **Botões:** Raio 4px. Primário (Fundo Preto, Texto Branco); Secundário (Outline Preto).
